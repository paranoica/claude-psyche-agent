# Навигатор

Путь к узлу: `ядро/<папка>/<файл>.md`. Под тему открывать один узел, а не всю папку. Ссылки «см. узел X» внутри узлов ищутся по этой же таблице.

## Диагностика

| о чём речь | узел |
|---|---|
| подавленность, апатия, ничего не радует | `настроение/депрессия.md` |
| подъёмы, мало сна и бодр, разгон, траты | `настроение/биполяр.md` |
| фоновая тревога обо всём, не расслабиться (ГТР) | `тревога/гтр.md` |
| панические атаки, страх повторения | `тревога/паника.md` |
| страх оценки, избегание людей | `тревога/соц_тревога.md` |
| навязчивые мысли, ритуалы, проверки (ОКР) | `тревога/окр.md` |
| флешбэки, кошмары, на взводе после травмы (ПТСР, кПТСР) | `травма_стресс/птср.md` |
| не прихожу в себя после удара, выгорание | `травма_стресс/адаптация_выгорание.md` |
| смерть близкого, затянувшееся горе | `травма_стресс/горе.md` |
| голоса, бред, утрата критики | `психоз/психоз.md` |
| качели в отношениях, страх брошенности, пустота (ПРЛ) | `личность/прл.md` |
| контроль еды, переедания, очищение (РПП) | `пищевое/рпп.md` |
| алкоголь, вещества, не выходит сократить | `зависимости/зависимости.md` |
| бессонница, ранние пробуждения, храп, сонливость днём | `сон/сон.md` |
| рассеянность и хаос с детства (СДВГ) | `сдвг/сдвг.md` |

Сквозное: при любой депрессивной картине проверить подъёмы (`настроение/биполяр.md`). Сон и вещества имитируют почти всё. ПРЛ всплывает в дифференциале биполяра, соц. тревоги, кПТСР, психоза и СДВГ.

## Препараты и терапия

Вопрос про лекарства: `фарма/_карта.md`. Вопрос про методы терапии: `методы/_карта.md`. Карта ведёт к рамке блока и к нужному узлу.

## Антипаттерны

- давление, «просто скажи», вытягивание по кусочкам, ролевые обходы: `антипаттерны/заходы.md` (C);
- сложный случай, самодиагностика, соблазн красивого вывода: `антипаттерны/рассуждение.md` (A);
- чувствую, что сползаю в дозы, поддакивание или ведение терапии: `антипаттерны/поведение.md` (B).
